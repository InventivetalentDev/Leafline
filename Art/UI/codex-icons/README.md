# HUD icons by Codex

Two HUD icons generated by Codex (OpenAI's built-in image tool) on 15 Nov 2026 from the Leafline concept boards, as part
of a placeholder UI pack made in a separate Codex worktree. Only these two ship; the pack's panels, buttons and meter
images were not used (the panels are Cookiehero's, `Art/UI/cookiehero/`). `prompt-set.txt` records the prompts for the
whole pack.

| File in the game | What it is |
|---|---|
| `Content/Leafline/UIRaw/Icon_Ant.pngraw` | 128 x 128, white side-profile ant facing right, tinted by the game; returning workers draw it mirrored |
| `Content/Leafline/UIRaw/Icon_Leaf.pngraw` | 128 x 128, white bitten leaf, tinted by the game |

The other HUD icons are still the script-made ones from `Tools/ui_icons.py`.
