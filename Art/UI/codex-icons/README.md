# HUD icons by Codex

HUD icons generated by Codex (OpenAI's built-in image tool) on 15 Nov 2026 from the Leafline concept boards, in a separate
Codex worktree. All are 128 x 128 white masks on transparent; the game tints them with its colours. The prompts:
`prompt-set.txt` (the first placeholder pack, which gave the ant and the leaf) and `prompt-set-hud-icons.txt` (the other
eight). The pack's panels, buttons and meter images were not used (the panels are Cookiehero's, `Art/UI/cookiehero/`).

| File in the game (`Content/Leafline/UIRaw/`) | What it is |
|---|---|
| `Icon_Ant.pngraw` | side-profile ant facing right; returning workers draw it mirrored |
| `Icon_Leaf.pngraw` | bitten leaf (the carried piece) |
| `Icon_LeafPile.pngraw` | three leaf fragments (the colony total) |
| `Icon_Grip.pngraw` | three hooked feet gripping bark |
| `Icon_Sheltered.pngraw`, `Icon_Partly.pngraw`, `Icon_Exposed.pngraw` | a leaf windbreak: full, short, none |
| `Icon_BirdGlide.pngraw`, `Icon_BirdDive.pngraw` | the bird circling, and stooping |
| `Icon_Wind.pngraw` | wind stream with an arrowhead, turned to the wind's direction on screen (the drawn arrow is the fallback) |

`Tools/ui_icons.py` still makes the original procedural icons and would overwrite these if run.
